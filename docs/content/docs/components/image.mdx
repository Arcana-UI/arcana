## Import

```tsx
import { Image } from '@arcana-ui/core'
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | `string` | (required) | Image source URL |
| `alt` | `string` | (required) | Alt text (required for accessibility — use "" for decorative images) |
| `fallback` | `ReactNode` | - | Fallback content shown while the image is loading or when it fails to load. When `errorFallback` is also provided, `fallback` is only used during loading. |
| `errorFallback` | `ReactNode` | - | Content shown specifically when the image fails to load. Takes precedence over `fallback` in the error state. When the image has failed, the underlying `<img>` element is removed from the rendered output so the browser cannot paint a broken-image icon behind the fallback. |
| `aspectRatio` | `number \| 'square' \| 'video' \| 'portrait'` | - | Aspect ratio constraint |
| `objectFit` | `enum` | `"cover"` | How the image fills its container |
| `lazy` | `boolean` | `true` | Use native lazy loading |
| `radius` | `enum` | `"none"` | Border radius |
