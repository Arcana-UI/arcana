## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultTheme` | `ThemeId \| null \| 'inherit'` | `"light"` | Default theme to use when no stored preference exists and system detection is not used. Pass `null` or `"inherit"` to leave the existing `data-theme` attribute on `<html>` untouched — useful when the host app manages the attribute itself (e.g. a playground rendering arbitrary themes, or SSR that has already written the attribute). |
| `storageKey` | `string` | `"arcana-theme"` | localStorage key for persisting theme preference. |
| `enableTransitions` | `boolean` | `false` | When `true`, add smooth CSS transitions during theme changes. |
| `customThemes` | `readonly string[]` | - | Additional theme ids beyond the built-in set. When provided, these are considered valid stored values and are included in the `themes` array exposed via context. |
